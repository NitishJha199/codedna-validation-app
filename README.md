# CodeDNA Validation App

A small two-service application used to validate CodeDNA's end-to-end
DevSecOps evidence ingestion and correlation.

## Services

- order-api
- inventory-api

This repository is intentionally kept independent from the CodeDNA source
repository so onboarding, historical reconciliation, webhook ingestion,
SBOM processing, security correlation, and deployment evidence can be
validated as an external repository.
